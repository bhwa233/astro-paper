# 任务

你要把下面的纽约时报畅销书榜候选证据，翻译并改写成一篇中文《每周图书推荐》。证据字段大多是英文，你需要翻译并改写成自然中文。

- 任务：{task}
- 日期：{date}

# 输入证据

```md
{source_text}
```

# 输出要求

只输出一个合法 JSON 对象，不要输出 Markdown、frontmatter、代码围栏或任何解释。

原书名、作者、封面链接由脚本从证据回填，你不要输出它们。你只需为每本书产出
「中文书名、类型、内容简介，以及荣誉与书评的译文」这几个语义字段。archive 层会用
`fiction`（小说）、`nonfiction`（非虚构）、`young_adult`（青少年）
三个数组分别对应证据里的「小说候选」「非虚构候选」「青少年候选」，
按 `rank` 与证据顺序合并，生成最终博客文章。

JSON 结构必须严格如下（`rank` 与各自证据列表里的序号一一对应）：

- 输入中实际提供的每一类候选必须全部输出，每个 `rank` 恰好出现一次，不得漏项、重复或自行增删候选。
- 某一类可能只有一两本甚至没有；证据里缺席的类别，对应数组输出为空数组 `[]`，不要自行补足。

```json
{
  "description": "本周推荐图书的类型与看点，40字以内",
  "fiction": [
    {
      "rank": 1,
      "title_zh": "中文书名",
      "genre_zh": "根据简介判断并用中文标注类型，如长篇小说、悬疑惊悚、爱情、科幻等，用、分隔",
      "summary": "把英文简介翻译并改写成一段自然中文，交代题材与看点，不剧透关键结局；若证据无简介则只写「暂无官方简介」，不要靠书名推测",
      "honors": "把证据「荣誉」字段翻成中文，多条用、分隔；证据为「-」时输出空字符串",
      "praise": "把证据「书评」字段里的引文翻成中文，格式为「引文」—— 出处；证据为「-」时输出空字符串"
    }

  "nonfiction": [

  ],
  "young_adult": [
    { "rank": 1, "title_zh": "…", "genre_zh": "如青少年奇幻、成长小说等", "summary": "…", "honors": "…", "praise": "…" }
  ]
}
```

# 写作要求

- `title_zh`：把英文书名翻成通行的中文译名；已有官方中文版书名就用官方名。原英文书名由脚本回填在括号里，你不用写。证据「中文书名」不是「-」时脚本会直接用它覆盖你的译名，你照常填写即可。
- `summary` 语气参考图书编辑荐书栏目，约 80–180 字，不要干巴巴罗列字段。
- 不要在 JSON 里输出作者或封面；它们由脚本回填。

## 三个证据字段怎么用

证据里的「简介」「荣誉」「书评」已经拆开，对应三种不同性质的信息，一一对应到三个输出字段，不要跨字段搬运：

- 「简介」是剧情正文，翻译改写后进 `summary`。
- 「荣誉」是媒体书单与榜单头衔（如入选某杂志年度书单、读书会选书），**照原文翻译**进 `honors`，不要加评价、不要扩写。
- 「书评」是带署名的评论引文，**照原文翻译**进 `praise`，保留出处署名。
- 严禁把书评人的评价（如「achingly intelligent」）当作对作品的客观描述写进 `summary`。

**`honors` 与 `praise` 只做翻译，不做创作。** 它们对应的证据字段为「-」时，一律输出空字符串——
这两段在文章里会整块省略，留空是正常且预期的结果，不要为了填满而自己写一句推荐语。

# 质量边界

- 不要编造证据里没有的作者、情节、获奖或销量数据。
- `honors` 与 `praise` 只能来自对应证据字段。证据为「-」时必须输出空字符串，不得自拟一句荣誉或书评，也不得把简介改写成引文。
- 不要输出任何形式的推荐语或阅读建议（「适合……读者」「值得一读」「读来颇有冲击力」等）。作品好在哪里，只由证据里的荣誉与书评说话。
- `genre_zh` 依据简介合理归类即可，不确定就给宽泛类型，不要杜撰具体子类。
- 漫画/图像小说若是系列的某一卷，可在简介中点明是系列续作，但不要编造未提供的剧情。
- 证据里简介为「-」或缺失时，`summary` 只写「暂无官方简介」，严禁凭书名、类型或作者猜测情节、主题或风格（如「从书名气质看」「此类作品往往」都算推测，禁止）。
- 不要把英文字段原样堆进正文，要翻译改写。
- 不要出现「待补充」「示例」「信息不足」「无法判断」等占位文字；但简介缺失时的「暂无官方简介」是允许的固定写法，不受此限。
