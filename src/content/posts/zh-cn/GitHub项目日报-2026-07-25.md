## 1. [block/buzz](https://github.com/block/buzz)

- 项目总结：Buzz 是可自托管的人与 AI agent 协作工作区，将消息、代码、工作流和审计记录统一到签名事件日志中。
- 技术栈：Rust / Nostr relay / Axum WebSocket 与 REST / PostgreSQL / Redis / MinIO / Tauri / React / Docker / JSON CLI
- 使用场景：适合需要让人类与多个 agent 在同一项目空间中协作、审查代码并保留可检索记录的开发团队。
- Stars：11.9k
- Forks：944
- 今日新增 Stars：2.5k

## 2. [alibaba/open-code-review](https://github.com/alibaba/open-code-review)

- 项目总结：Open Code Review 是面向 Git diff 的 AI 代码审查 CLI，通过确定性流程配合 LLM agent 生成精确到代码行的结构化评论。
- 技术栈：Go / Git 2.41+ / LLM agent / OpenAI 与 Anthropic 兼容接口 / CLI / MCP / GitHub Actions、GitLab CI、Gerrit 集成
- 使用场景：适合将 AI 审查接入本地开发或 CI/CD 流程，用于缺陷扫描、规则匹配和变更评审。
- Stars：12.9k
- Forks：886
- 今日新增 Stars：431
