## 1. [cloudflare/computer](https://github.com/cloudflare/computer)

- 项目总结：Cloudflare Computer 将 Durable Object 中的 SQLite 状态抽象为可执行的虚拟文件系统，并通过多种后端为 Agent 提供工作空间。
- 技术栈：TypeScript / Cloudflare Durable Objects / SQLite / Workers RPC / capnweb / FUSE / Dynamic Workers
- 使用场景：适合在 Cloudflare Workers 环境中为 Agent 构建可读写文件、运行 Shell 或 JavaScript 的实验性工作空间。
