## 1. [TencentCloud/TencentDB-Agent-Memory](https://github.com/TencentCloud/TencentDB-Agent-Memory)

- 项目总结：项目为 AI Agent 团队提供统一记忆中心，将对话、技能、文档和代码关系整理为可共享、可治理的记忆资产。
- 技术栈：TypeScript / Memory Core、Memory Hub、Proxy / BM25、向量检索、RRF / OpenClaw、Hermes、Claude Code、CodeBuddy、SDK
- 使用场景：适合需要跨会话复用项目上下文、沉淀工作技能并为不同 Agent 分配知识权限的团队。

## 3. [cloudflare/computer](https://github.com/cloudflare/computer)

- 技术栈：TypeScript / Cloudflare Durable Objects、SQLite、Workers RPC、Dynamic Worker、Container、FUSE、capnweb
- 使用场景：适合为 AI Agent 构建持久化工作区、文件读写和命令执行原型，但 README 明确标注为预览版本，不适合生产使用。
