## 1. [cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design)

- 项目总结：diagram-design 是一套为 Claude Code、Codex 等编程助手设计的图表生成技能，可生成符合编辑设计风格的 27 种 SVG 图表，并支持从 draw.io 或 Mermaid 导入重绘。
- 技术栈：HTML / SVG / Claude Code 技能 / Agent Skills
- 使用场景：适合需要在博客、演示文稿或技术文档中生成风格统一、可定制品牌配色的专业图表的开发者与内容创作者。
- Stars：10.2k
- Forks：668
- 今日新增 Stars：3.0k

## 2. [macro-inc/macro](https://github.com/macro-inc/macro)

- 项目总结：Macro 是一个开源的团队一体化工作空间，将邮件、聊天、文档、任务、CRM 与 AI 智能体统一在单一界面中，并通过双向链接和团队级记忆实现数据互通。
- 技术栈：Rust / SolidJS / CRDT / MCP
- 使用场景：适合希望用单一系统替代 Slack、Notion、Linear 等多个工具，并让 AI 智能体协作处理日常工作的中小团队。
- Stars：1.8k
- Forks：221
- 今日新增 Stars：325

## 3. [semantica-agi/semantica](https://github.com/semantica-agi/semantica)

- 项目总结：Semantica 是一个面向 AI 智能体的图原生基础设施，可将企业数据构建为上下文图与知识图谱，提供确定性推理、决策留痕和 W3C PROV-O 溯源能力。
- 技术栈：Python / RDF / LPG / SPARQL / Datalog / SHACL / Neo4j / Databricks / Snowflake
- 使用场景：适合金融、医疗、政务等受监管行业中需要可审计、可解释 AI 决策的团队，用于构建合规的知识图谱与决策记录系统。
- Stars：5.7k
- Forks：623
- 今日新增 Stars：834

## 4. [stablyai/orca](https://github.com/stablyai/orca)

- 项目总结：Orca 是一个面向并行智能体的应用开发环境（ADE），可同时运行 Codex、Claude Code、OpenCode 等多种 CLI 智能体，每个智能体独立工作树并统一追踪。
- 技术栈：TypeScript / Electron / WebGL / SSH / git worktree
- 使用场景：适合需要同时管理多个编码智能体并进行并行开发、对比结果与远程执行的开发者。
- Stars：43.8k
- Forks：3.1k
- 今日新增 Stars：1.2k

## 5. [msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents)

## 6. [shiyu-coder/Kronos](https://github.com/shiyu-coder/Kronos)

- 项目总结：Kronos 是一个针对金融 K 线数据预训练的开源基础模型，通过分层离散 token 化与自回归 Transformer 实现对 OHLCV 序列的预测与微调。
- 技术栈：Python / PyTorch / Qlib / Hugging Face Transformers
- 使用场景：适合量化研究者与开发者用于金融时间序列预测、微调自定义市场数据以及构建回测策略。
- Stars：36.9k
- Forks：6.2k
- 今日新增 Stars：277

## 7. [NanmiCoder/MediaCrawler](https://github.com/NanmiCoder/MediaCrawler)

## 9. [infiniflow/ragflow](https://github.com/infiniflow/ragflow)
