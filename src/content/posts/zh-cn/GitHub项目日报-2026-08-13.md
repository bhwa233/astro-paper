## 1. [cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design)

- 项目总结：为 Claude Code 等编码代理设计的图表生成技能，输出自包含 HTML/SVG 的编辑级图表，强调无阴影、无通用模板风格。
- 技术栈：HTML / SVG / Claude Code / Codex / Pi 技能，无构建步骤、无外部依赖
- 使用场景：适合需要在文档、博客或演示中快速生成品牌化、编辑级图表的开发者和内容创作者。

## 2. [semantica-agi/semantica](https://github.com/semantica-agi/semantica)

- 项目总结：构建可审计、可解释 AI 系统的图原生基础设施，提供上下文图、决策记录、溯源与规则推理。

- 使用场景：适用于金融、医疗、政务等受监管行业中需要可审计 AI 决策和复杂知识图谱的平台团队。

- Forks：696
- 今日新增 Stars：727
