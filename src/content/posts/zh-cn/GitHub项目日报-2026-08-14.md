## 1. [cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design)

- 项目总结：一个为 AI 编码代理设计的图表生成技能，用静态 HTML/SVG 输出编辑级图表，可导入 draw.io/Mermaid 并匹配品牌风格。
- 技术栈：HTML + SVG；Claude Code / Codex / Pi 的 Agent Skill
- 使用场景：适合需要为博客、文档、幻灯片生成编辑级图表并保持品牌一致的设计师、写作者和开发者。
