## 2. [cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design)

- 项目总结：为 Claude Code、Codex 等 AI 编码代理设计的编辑级图表技能包，输出自包含 HTML+SVG 图表，支持从 draw.io/Mermaid 源重绘。
- 技术栈：HTML / SVG / Claude Code、Codex、Pi 的 Agent Skills 技能包 / draw.io 与 Mermaid 导入
- 使用场景：适合写作者和开发者用 AI 代理生成品牌化架构图、流程图示，或把复杂图表快速重绘为统一风格。
- Stars：18.6k
- Forks：1.1k
- 今日新增 Stars：1.6k

## 3. [cursor/plugins](https://github.com/cursor/plugins)

- 项目总结：Cursor 官方插件仓库，定义 .cursor-plugin 插件规范并汇集官方插件，覆盖开发工具、生产力与集成类能力。
- 技术栈：TypeScript / .cursor-plugin/plugin.json 插件清单
- 使用场景：适合 Cursor 用户安装现成插件增强编辑器与代理工作流，也适合开发者参考规范编写自有插件。

- Forks：233
- 今日新增 Stars：152

## 4. [cactus-compute/needle](https://github.com/cactus-compute/needle)

- 项目总结：面向手机、可穿戴设备、智能家居和机器人的超轻量基础模型，将模型权重打包为 14MB 单文件引擎，支持工具调用与结构化提取。
- 技术栈：Python / JAX / LoRA / CQ2 量化 / Hugging Face / Simple Attention Network
- 使用场景：适合需要在端侧低功耗设备上运行推理的开发者，用于工具调用、设备控制和文本结构化提取。
- Stars：6.1k
- Forks：402
- 今日新增 Stars：551

## 5. [unslothai/unsloth](https://github.com/unslothai/unsloth)

- 项目总结：提供桌面应用与 Web UI，用于本地运行、微调和部署 LLM、扩散模型等，支持 LoRA/QLoRA、GRPO、GGUF 导出等功能。
- 技术栈：Python / Tauri 桌面应用 / PyTorch / MLX / llama.cpp / CUDA / ROCm / Vulkan / GGUF
- 使用场景：适合个人开发者和研究者在本地 GPU 或 Mac 上运行、微调和导出模型，并可将本地模型接入 Claude Code、Codex 等代理。
- Stars：72.0k
- Forks：6.5k
- 今日新增 Stars：435
