## 2. [zedeus/nitter](https://github.com/zedeus/nitter)

- 项目总结：轻量级、注重隐私保护的第三方 Twitter 前端，无需客户端 JavaScript 且不直接连接官方追踪服务。
- 技术栈：Nim / libsass / Redis (Valkey) / Docker
- 使用场景：适合注重隐私防护的用户，用于在无脚本环境下浏览推文、个人主页及订阅 RSS 源。
